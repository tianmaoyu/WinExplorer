## 修了什么

**展开的子文件夹会莫名其妙变空（ADR 0024）**

树形展开时如果某一层恰好在读的那一刻读失败（网络卷抖一下、权限被系统收回一瞬间），
原来会把「读失败」当成「这个文件夹是空的」缓存下来，还会把之前读好的内容一起抹掉——
表现就是展开过的目录突然空了，刷新也回不来。现在：

- 读失败只记状态，旧内容继续显示，行上给一个警告三角并说明原因；
- 失败后按 0.5s / 1.5s / 4s 自动重扫，最多三次；
- 读取加了 5 秒超时兜底（对齐主目录），挂死的网络卷不会再把刷新一起卡掉；
- 读取进行中又触发的刷新不再被丢弃，会排队补读一次。

**点收藏夹时侧边栏闪一下（ADR 0025）**

从目录 a 点 b，高亮会先跳到 b、弹回 a、再回到 b。原因是侧边栏选中态读的是「已落地」的目录，
而它要等异步读完成才更新。现在点击的那一帧选中态就跟着走，读完再以磁盘为准；
没打开成功则会退回原目录，不会停在没去成的位置。

## ⚠️ 首次打开会被 Gatekeeper 拦下

包是 **ad-hoc 签名、未经 Apple 公证**（没有付费开发者账号），从网上下载后第一次打开会提示
「无法验证开发者」或「应用已损坏，你应该将它移到废纸篓」。后者是假警报。

1. **图形界面**：右键点 WinExplorer →「打开」→ 弹窗里再点「打开」。只需一次。
2. **命令行**（一次即可）：
   ```bash
   xattr -dr com.apple.quarantine /Applications/WinExplorer.app
   ```

## 顺手精简了工具栏（ADR 0026）

「粘贴」和「新建文件夹」两颗按钮从工具栏移除了 —— 前者在没有可粘贴内容时长期是灰的，
后者用得少。功能一个没少：<kbd>⌘V</kbd> / <kbd>⇧⌘N</kbd> 照旧，右键菜单和「文件」菜单里都在。
